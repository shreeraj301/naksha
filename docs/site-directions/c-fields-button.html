Usage

import { Button } from "naksha";

<Button variant="primary" onPress={save}>Save changes</Button>
<Button iconStart="plus">New note</Button>
<Button variant="primary" isPending={saving}>Saving</Button>

Props

PropValuesDefault
variantprimary, secondary, ghost, highlight, dangersecondary
sizesm 32, md 40, lg 48 (36, 44, 52 on touch)md
iconStart, iconEndan icon name or a nodenone
isPendingshows a Spinner, ignores presses, stays focusablefalse
onPressmouse, touch, Enter and Space

Best practices

Primary, in ink, is for the one thing the view is for. Put a secondary beside it, and use ghost in toolbars, cards and dense rows. Danger is for actions that are hard to undo, always behind a confirm step or an Undo toast.
