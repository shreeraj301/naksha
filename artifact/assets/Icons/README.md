# Icons

38 Lucide icons (ISC licence), redrawn with a drafting pen: 24 grid, 1.5 stroke, square caps, mitred joins. Single ink: the files are drawn in ink `#151413` (`stone-950`); in code, inline them and set `stroke="currentColor"` so they take a text token.

Use at `size-icon-sm` (16) inside controls, `size-icon-md` (20) in alerts and navigation, `size-icon-lg` (24) standalone. To add one, copy its SVG from lucide.dev and set `stroke-width="1.5" stroke-linecap="square" stroke-linejoin="miter"`.
